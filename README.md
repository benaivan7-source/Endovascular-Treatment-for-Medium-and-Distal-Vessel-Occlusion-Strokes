# Endovascular-Treatment-for-Medium-and-Distal-Vessel-Occlusion-Strokes
The complete protocol, fully extracted study-level analytical dataset, statistical code, and software dependency logs required to replicate all frequentist and Bayesian meta-analyses for the manuscript "Endovascular Treatment for Medium and Distal Vessel Occlusion Strokes" by Bena Nnang et al.
